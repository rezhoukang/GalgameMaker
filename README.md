# Galgame Maker（互动视频制作器）

Vue 3 + Pinia + Vite · Go + Gin + SQLite。编排视频与 HTML 内容，导出独立播放器。

## 启动

```powershell
cd backend
go run .
```

另开终端：

```powershell
cd frontend
pnpm dev
```

前端 http://127.0.0.1:5173 ，后端端口 8787。
数据库位于 `backend/Index SQLite/galgame.db`。
应用配置和撤回签名密钥保存在 `config` 表。

## 文件导航

空白处右键新建文件夹；文件夹右键可新建子文件夹、画布、重命名和删除；画布右键可重命名、删除。
导航根目录不显示，不能重命名或删除。画布就是一个工程。
文件夹和工程使用 `delete_at` 时间字段软删除，正常记录为 NULL；删除文件夹会同时标记其下尚未删除的文件夹和工程。节点、端口和素材保留，已删除工程不再显示，也不能通过旧页面读取、编辑或导出。回收站恢复入口后续提供。
保留中的目录不可复用；新建同名工程自动加序号。初始化操作仍会彻底清空全部项目数据和素材。

## 节点和端口

- 每个工程恰好一个不可删除的根节点，层级为 1。
- 点击节点右侧加号：新建普通出端口和下一层节点；右键加号：输入目标节点哈希创建魔法出端口。
- 普通连接构成一棵树。其他节点恰好一个普通入端口，禁止普通环；魔法连接允许回跳，不参与层级和布局。
- 数据库 `nodes`（模型 `Node`）保存剧情节点，`ports`（模型 `Port`）只保存出端口。`export_hash` 直接指向目标节点，入端口由前端生成。
- `level` 在结构事务中计算，界面的出端口数量根据端口列表实时统计。端口的 `option_content` 是选项文案，`is_show` 决定是否展示选项。
- 节点名称与素材目录分离，改名不会影响素材。编辑阶段允许尚未导入素材；导出前必须补齐。
- 播放起点按工程独立设置；根节点与播放起点分别管理。

## 节点内容

节点只保存 `content_path`，即相对于工程目录的内容入口路径（当前为 HTML 页面），不再保存 `video`、`html_file` 或 `asset_dir`。端口统一跳转目标节点，不再区分内容类型。

- 导入 MP4 自动生成 HTML 页面，视频通过页面内的 `<video>` 引用。
- 导入 HTML 会替换当前节点内容。支持资源已内嵌的单文件 HTML，或使用在线资源的页面；不会自动收集电脑上其他文件。
- 每次上传生成 `.content/<版本标识>/index.html`；视频与页面保存在同一版本目录。版本不可覆盖，复制节点共享路径，撤回恢复之前的路径。
- 导出只复制当前使用的内容版本及其资源，共享版本只打包一次，不携带历史素材。

## 编辑和撤回

- 拖动空白区域、按住空格拖动、中键拖动或 Ctrl 拖动可平移；Ctrl 滚轮缩放，普通滚轮平移。
- 节点右侧外部圆形按钮的 `−` 收起更深层节点，保留当前节点和下一层；收起后显示 `+`，不显示数量。没有更深层节点时不显示按钮，魔法连接不参与折叠。
- Ctrl+Z 撤回，Ctrl+Shift+Z / Ctrl+Y 重做；Ctrl+0 适应画布。
- 选中节点后 Ctrl+C / Ctrl+V 复制、粘贴节点 HTML 内容引用。身份、名称、层级、端口连接不被覆盖。
- Delete 删除选中节点的普通子树，F2 打开节点属性；输入框内保留原生文字快捷键。
- 当前工程最近 50 步节点编辑历史缓存到 localStorage，刷新后重新打开工程仍可撤回。历史恢复同步写回数据库。
- 删除子树只沿普通连接；相关魔法连接随之移除，但魔法连接指向的其他分支保留。
- 节点删除和素材替换保留旧素材版本，供撤回使用。删除整个工程或文件夹也保留素材，导航软删除不在节点撤回历史中。
- 服务端验证历史签名和当前版本；旧页面不能通过撤回覆盖其他页面的新修改。

## 导出

导出前检查节点内容、起点、连接目标、普通树约束和选项配置。

- 全部出口显示选项：视频结束后由玩家选择。
- 恰好一个出口且取消“显示选项”：视频结束后自动继续。
- 没有出口：播放结束后保留视频末帧或 HTML 页面，结局文字由素材本身承载；可点击“重来”。
- 隐藏出口不能与其他出口混用，配置冲突会阻止导出。

导出 `index.html` + `dist/`，每个节点拥有 `#/node/<hash>` 路由，可直接访问、刷新或前后导航。
所有节点均通过 iframe 加载 HTML。页面内视频播放结束后通知播放器显示选项或自动继续；纯 HTML 页面通过“继续”进入选项，终点保留页面。视频加载错误会提示，不会误触发自动跳转；浏览器限制自动播放时可使用视频自身的播放按钮。
导出的页面注入内容通知脚本；自定义 HTML 也可调用 `window.dispatchEvent(new Event('galgame:complete'))` 主动结束内容。播放器仅处理当前页面发来的通知，跳转时销毁旧页面，音量设置跨节点保留。页面在仅允许脚本的 iframe 沙箱中运行，不允许直接操作播放器或顶层导航。

导出目录中的 `index.html` 可直接打开，也可使用静态 HTTP 服务。引用在线资源的 HTML 仍需要网络。
