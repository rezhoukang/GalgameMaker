# Galgame Maker（互动视频制作器）

把做好的 HTML / MP4 素材编排成互动剧情，导出为单页 HTML 播放器。类似 B 站互动视频。

技术栈：**Vue 3 + Pinia + Vite（前端） · Go + Gin + SQLite（后端）**。

---

## 只有两个东西

### 节点（Node = 一个文件夹）

一张思维导图卡片，对应一个文件夹。文件夹里放一个 HTML 页面和/或多个 MP4 视频，导出后成为故事线的一站。

- 每个节点有唯一的**哈希**（标题栏 `#` 按钮复制），魔法端口靠它跳转。
- 可设为「开始」节点（▶），可折叠/展开子树。
- 删除节点会连端口、配对端口、磁盘文件夹一起删。

### 端口（Port = 一条连接）

本质是「**节点 — 端口 — 节点**」：一个端口连接两个节点。端口弹窗里能看到并修改它的**上一节点**和**下一节点**（粘贴节点哈希即可改）。

- **出/入端口**：没有本质区别，只是为了前端好看——出端口显示在节点右侧、入端口在左侧。它们**共用同一个哈希、名字相同、配置共享**（改一端另一端同步）。
- **魔法端口**：一种特殊端口——画布上不画线，可跨画布按哈希跳到任意节点（纯红 `#ef4444`）。

---

## 怎么用

- 点节点右侧 **＋** → 新建一个出端口 + 空白下一跳节点（自动配对）。
- 右键 **＋** → 新增魔法端口（粘贴目标节点哈希）。
- 点端口球 → 编辑弹窗：改名 / 跳转类型（MP4 / HTML）/ 结局内容 / 修改上一下一节点。
- 点节点标题栏 **#** 复制哈希；**编辑** 导入 HTML、插入视频、设为开始。

---

## 运行

- 后端：`cd backend && air`（端口 8787）
- 前端：`cd frontend && pnpm dev`（端口 5173；Windows 中文路径用 `node node_modules\vite\bin\vite.js`）
- 导出：右上角「导出 Galgame Output」→ 生成单页播放器 `index.html` + `dist/` 资源目录（视频播完弹选项 / 页面 iframe 展示 / 结局黑屏文字）。
